# Loopy · web page

The Loopy website: landing page, help and legal pages (Spanish). Built with TanStack Start, React, TypeScript and Tailwind CSS, and prerendered to static HTML.

Live at https://loopy-support.github.io/loopy-web-page/

## Development

```sh
bun install
bun run dev
```

`bun run build` writes the static site to `dist/client`. Every push to `main` deploys it to GitHub Pages (`.github/workflows/pages.yml`).
